Template driven form example

Template Driven Forms rely on directives defined in the FormsModule.The below example uses NgModel and NgForm

NgForm creates a top-level FormGroup instance, binds it to a form element to track form value and validation status.

Some of the built-in validators are required, minlength, maxlength & pattern

@if (username.invalid && username.touched && username.errors?.['required']) { Username is required. }
@if (username.errors?.['minlength']) { Username must be atleast more than 5 characters. }
@if (password.invalid && password.touched) { Password is required. }
