Search using Rxjs

An input field of type text is created to accept a value. When user enters the value, the value is stored in a subject, which then before filtering the list, make use of startWith(), debounceTime(), distinctUntilChanged(), and switchMap() operators of Rxjs.

startWith() operator is used to show all the list even if the user input value is empty.

debounceTime() operator is used to wait for some time period to make api call or filter the list.

distinctUntilChanged() operator is used to not to duplicate the api calls or filter the list if the current and previous value are same.

switchMap() operator is used to cancel api call if current value has changed.
